# 《砰砰小队》美术与世界观圣经 — 百怪夜巡

> **状态**：2026-09-06 起唯一有效的 Boom 视觉与世界观规范。
> 本文取代此前的糖果嘉年华、Bubble Captain、果冻/气球敌人与暖橙×亮青风格。
> 生图、3D 建模、场景、UI 与特效任务均先读本文；机器可读提示词见
> `shared/assets/styles/boom-3d/contract.yaml`。

## 1. 一句话定位

> 灵印崩裂、百怪夜行；年轻女灯使背负镇夜灯匣，在中国志怪式的失序夜路上收伏怪印。

游戏仍是竖屏、单手、俯视、60–90 秒一局的轻量割草动作游戏。世界观服务于
“一眼看懂、击杀可读、可不断增加地图/妖怪/法器”的目标，不做正统西游、三国或
现实历史改编。

## 2. 世界观规则

- **灾变**：维系人、地、怪边界的“灵印”碎裂，残印令地方旧物、传说与游魂化为百怪。
- **玩家身份**：巡夜司最年轻的女灯使；她的灯匣可收纳怪印、将其净化，并短暂借出其能力。
- **战斗含义**：击杀并非消灭生命，而是收回失控怪印；局内升级是临时拼合怪印，局外成长是修复灯匣与异闻档案。
- **地图逻辑**：每张地图是一则地方异闻。首章为“雨夜古镇”；后续可扩展山神庙、荒村戏台、河渡、灯市、云上天街。
- **怪物语气**：奇异、可读、带一点顽皮；不血腥、不恐怖、不使用真实宗教仪式或现实历史人物。

## 3. 主角：巡夜女灯使

### 3.1 设定图与实机的分工

设定图可表现布料、纸纹、旧铜和人物情绪；实机必须压缩到 **2.75–3 头身**、少分件、
俯视三分之四可读。小屏里优先看到“短披风 + 方灯匣 + 暖色灯光”，不是衣服上的细碎挂件。

### 3.2 不可丢失的识别件

- 黑色短发，以朱红发绳束起；额间有小型朱砂印。
- 深靛蓝短披风、米白交领短衣、朱红腰绳、深色短靴。
- 背部为方形纸灯匣，只有一面暖色发光窗；灯匣是主角最优先的背面识别件。
- 手部基础底图/模型不持武器。镇夜灯、符纸、镇尺等武器和攻击特效必须作为独立层。

## 4. 美术风格：新国风轻 Q 原生 3D

### 4.1 总纲

“国风动画里的小巡夜人”，不是写实道士、不是糖果玩具、也不是重度二次元立绘。
造型以低面数、哑光、清晰剪影与有限材质实现；设定图可精致，实机的细节预算要克制。

### 4.2 材质与形状

| 类别 | 应使用 | 禁止 |
|---|---|---|
| 材质 | 米纸、布、深木、旧铜、潮湿石板、薄雾 | 糖果塑料、果冻、气球、高亮玩具漆、皮肤毛孔级写实 |
| 形状 | 方灯、短披风、圆角木件、符纸、简洁折线 | 满身尖刺、密集金属零件、巨大武器、复杂盔甲 |
| 光照 | 深夜冷环境光 + 局部暖灯；柔和短阴影 | 全黑画面、影视级强逆光、硬边黑影、频闪 |
| 画面 | 俯视三分之四、实机轮廓优先 | 仰视英雄海报、角色占据全部战场、厚涂背景替代可玩地面 |

### 4.3 语义色板

| 名称 | HEX | 用途 |
|---|---|---|
| 墨夜蓝 | `#18233B` | 夜景底、远景、阴影环境 |
| 披风靛蓝 | `#314A78` | 主角外披、友方识别 |
| 米纸白 | `#F4E8D0` | 主角内衣、符纸、UI 中性底 |
| 朱砂红 | `#B84235` | 主角红绳、封印、危险预警（小面积） |
| 灯火琥珀 | `#F2B84B` | 玩家灯匣、路径、安全和奖励高光 |
| 灵雾青绿 | `#5FC5AD` | 妖力、收怪、特殊技能 |
| 雾灰青 | `#98B7C4` | 幽魂类敌人与远景雾气 |
| 石板灰 | `#425064` | 地面、墙体、非交互结构 |

规则：全屏以墨夜蓝/石板灰为底；暖灯黄只负责玩家、安全点和极少量引导；朱砂红只作封印或危险信号。
避免旧方案中的全屏暖橙、亮青能量与糖果饱和色冲突。

## 5. 场景与怪物

### 5.1 首章：雨夜古镇

- 可玩地面：深灰蓝湿石板，低反射水痕，不能黑到吞掉角色脚部。
- 结构件：窄桥、木门、石灯、纸灯笼、屋檐、河道边缘；场景外围讲故事，中部保持战斗留白。
- 关键照明：沿路暖色灯笼与主角灯匣共同构成路线和安全感。

### 5.2 敌人

第一批敌人优先使用纸偶、雾灵、灯影、石精等原创“怪印失控物”。形体必须在俯视小屏一眼区分；
怪物不使用血、牙、现实枪械、过度恐怖的肢体细节。危险通过预警圈、朱砂符纹与动画前摇表达。

## 6. 武器、特效与 UI

- 武器是独立视觉层：角色基础雪碧/模型必须不含手持武器。
- 第一件法器为“镇夜灯”：可有收纳、放灯、近战镇尺三种形态，但外形统一为木、旧铜、米纸与朱红流苏。
- 特效以灯火琥珀、灵雾青绿、纸符碎片、短暂朱砂封印为主；不使用泡泡、糖屑、气球碎片。
- UI 采用深靛底、米纸面、琥珀主按钮、朱砂危险态；圆角可亲和，但不再做糖果圆润塑料按钮。

## 7. 素材生产与验收

- 角色/怪物：透明 PNG；实机角色优先 512px 单帧或按 256px 单帧组织的动画条。
- 场景：优先低模原生 3D；如用贴图，地面必须可平铺、场景外围不遮挡战斗中心。
- 原始生成图与设计图放 `assets/references/`；运行时素材只放 `assets/images/`，单图不超过 512KB。
- 每批角色都需先检查透明 Alpha、缩略图可读性、武器是否错误烘焙进基础角色，再进行 Godot 导入。

## 8. 绝对禁止（返工红线）

1. 奶蛙、Bubble Captain、糖果嘉年华、果冻兵、气球兵及其旧色板；
2. 正统西游/三国人物与任何可识别的现有 IP 角色造型；
3. 照片级写实皮肤、真实枪械、血腥恐怖、黑色描边、全黑战场；
4. 把武器、攻击特效烘焙进无武器主角基础雪碧；
5. 为了精致而牺牲俯视小屏下的轮廓、移动可读性与性能预算。
