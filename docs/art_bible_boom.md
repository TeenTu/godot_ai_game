## 1. 风格总纲（一句话）

> **高饱和、暖色、圆润、软体——像一场永远亮着暖阳的游乐园气球大战。**
> 战场 = 暖橙的"我" vs 高饱和冷色的"敌群"，火力特效 = 亮青，危险 = 正红，奖励 = 金币金。
> 低对比柔光、无硬阴影、无写实材质、无文字。任何一张图单独拿出来都应该是"想让人戳一下的糖"。

### 1.1 为什么是"高饱和 + 暖 + 低对比"

| 视觉决策 | 依据 | 反例（禁止） |
|---|---|---|
| 高饱和 | 移动端小屏 + 俯视混战，低饱和在竖屏上糊成一团；高饱和让敌我 0.5 秒可辨 | 莫兰迪灰、工业风脏色 |
| 暖色打底 | 暖色（橙/米/金）在心理上=安全/可亲近，贴合"解压、无惩罚"基调 | 冷灰蓝底、暗黑地牢感 |
| 低对比柔光 | 高对比硬阴影制造紧张与看不清（违背支柱 C"压力可读"）；柔光让软体敌人"弹"得起来 | 写实 GI、强逆光剪影、霓虹频闪 |
| 大圆角 | 圆=无害、可压缩=可掌控（心理学依据见 §3） | 锐利尖刺堆砌、机械冷峻线条 |

- 荧光绿 `#00FF00` / 荧光粉（刺眼，违背防晕）
- 冷灰蓝底光（暗部不得往蓝紫走，往暖橙/红棕走）

## 3. 形状语言（圆润软体大圆角）

### 3.1 总原则

1. **剪影先圆后形**：任何对象先是一个"圆润的团块"，再在其上加特征（眼睛、引信、提手）。
   基础母形 = 球 / 胶囊 / 椭球 / 圆角立方（corner ≥ 半径的 30%）。
2. **无关节、少分件**：软体敌人不做四肢骨骼；要"动"就用整体变形（挤压拉伸、浮动、弹跳）。
   主角也只有 头/身/装饰 三层分件——俯视小屏 + 60fps，细碎部件是噪音。
3. **危险物允许锐角，但有配额**：炸弹兵引信、地刺、冰箱冰晶可出小锐角（三角形/星形），
   但单对象锐角元素占比 ≤ 20%，且必须**大块圆底托住**——锐角只负责"信号"不负责"主体"。
4. **表情传意**：眼睛 = 两个深色圆点 + 高光白点（俯视角向下看时清晰可见）；嘴巴可选弧线。
   敌人眼睛一律**憨/呆/圆**，即使愤怒也只皱眉头，不龇牙——它是"要你躲"，不是"要吃你"。

### 3.2 为什么圆 = 解压（评审用理论锚）

- **圆 = 无害信号**：自然界尖刺/棱角对应危险，浑圆团块对应幼崽/果实，触发"想碰、想捏"的趋近反应；
- **可压缩 = 可掌控**：受击先挤压变形再回弹（squash&stretch），把"被击中"翻译成"被捏了一下"，
  削弱挫败、放大逗弄感——这正是 design_boom §2.3"敌人质感=软体"的视觉兑现；
- **爆开无残留**：爆碎碎片用高饱和小圆块/小胶囊（果冻粒、纸屑、气球皮），飞散后快速消失，
  不产生"血腥残留"式的心理负担。

## 4. 光照与阴影风格

| 项 | 规格 | 说明 |
|---|---|---|
| 主光 | 单一暖白方向光，俯角 45–60° | 模拟"暖阳游乐园"，永远明亮 |
| 环境/补光 | 柔和，轻微冷色补光（青 `#2BD9FF` 极低强度） | 让物体暗部带一点点青，制造"通透感"而非脏感 |
| 阴影 | **无硬阴影**；如有 → 半透明暖棕 `#D98A3F`、模糊边缘、短投影 | 贴图不出投影；3D 场景内阴影仅一盏 DirectionalLight（design_boom §8.3） |
| 对比 | 低对比：亮部不曝白、暗部不落黑 | 高饱和但亮度跨度窄 |
| 轮廓 | 允许轻微自发光边缘 / 顶部柔光晕 | 让"泡泡感"从背景弹出来 |
| 特效 | 允许瞬时高亮（爆炸白闪 ≤15% 透明度 ≤50ms），**静止画面不得频闪** | 防晕三铁律（design_boom §3.3） |

**给生图 agent 的光照词**：`soft studio lighting, gentle diffuse, warm sunny carnival feel,
no harsh shadows, low contrast, bright cheerful`.

| 材质氛围 | 特征词（写进 prompt） | 归属 |
|---|---|---|

| 果冻 | `translucent jelly, wobbly, inner air bubbles, wet highlight` | 果冻兵、分裂兵、泡泡子弹 |
| 气球 | `high-gloss balloon skin, stretched sheen, bright saturated` | 水枪兵、炸弹兵 |
| 牛皮纸/纸板 | `matte kraft cardboard, subtle corrugation, dry flat` | 纸箱兵、可破坏木箱 |

## 6. UI 风格

| 项 | 规格 |
|---|---|
| 按钮 | 大圆角（圆角半径 ≥ 按钮高度的 25–30%）、高饱和底、暖白图标；**主操作=暖橙、信息/技能=亮青**；热区直径 ≥88px（design_boom §3.1） |
| 描边 | 无黑描边；如需轮廓用深一档同色系（如按钮深橙 `#D96A1F`） |
| 血条 | 分段块（每格=1 血，design_boom §7.1）：亮格暖白、失血格深橙碎裂感；整体暖橙到亮青渐变不用 |
| 图标 | 圆底卡片 + 单个圆润主体；金币=金币金圆片带 `$` 或星星；危险图标=红底白形；全部无细碎文字 |
| 飘字/数字 | 暖白普通 / 金币金暴击 / 连击放大 1.3×（§7.2），圆润字体，粗描边用暖棕 |
| 背景/结算 | 结算是暖橙到亮青的柔和渐变底 + 金币金星星元素，永不纯黑 |

## 7. 主角造型（暖橙"泡泡队长"）

> 全屏唯一大块暖橙。竖屏俯视下只有约 0.5–1cm 屏幕大小，所以造型必须**剪影读、特征少、色块大**。

**关键词**：`round capsule body, glossy candy-orange skin (#FF8A3D), big cyan goggles (#2BD9FF),
cream belly patch, tiny antenna ball, soft toy, cheerful, kawaii, no limbs needed`

- **身体**：上宽下略收的圆胶囊（高≈宽的 1.1–1.2 倍），暖橙糖渍软糖质感，高光点在左上（顶光方向）。
- **护目镜**：占脸部 70% 的亮青大圆镜（两枚圆镜或一体式），镜面白高光；戴在圆脑袋上像泳镜，可爱而非战术。
- **装饰**：头顶一根细短呆毛 + 顶端暖白小球；肚皮一小块暖白斑（`#FFF6E8`）增加"肚肚"的软感。
- **表情**：露一小截弧线微笑或没有嘴（镜片足够）。
- **配色占比**：暖橙 ≥ 70%、亮青 ≤ 20%（镜）、暖白点缀。**禁**：给主角加红/紫大块。

**背面/顶视可读性**：俯视时玩家主要看到"头顶圆 + 护目镜边 + 呆毛"，因此头顶也必须有亮青元素
（护目镜边缘露出一圈亮青环），保证任何角度一眼是"青镜橙身 = 我"。

## 9. 场景、地板与背景

| 层 | 内容 | 规格 |

## 11. 负面清单（返工红线，命中最少打回一项）

1. 黑色描边 / 黑色暗部 / 冷灰蓝暗部 → 一律用暖棕 `#B86A30` 系；
2. 写实材质（金属锈蚀、皮肤毛孔、布纹照片级）；
3. 出现文字、字母、Logo、水印（金币的 `$` 符号是唯一允许字符，且须为圆润字体）；
4. 主角身上出现红/紫/绿大块（敌我语义串色）；
5. 硬阴影、逆光剪影、暗黑氛围、夜景；
6. 尖刺、牙齿、爪、血、真实武器（枪械子弹）；
7. 强透视（角色必须接近正/斜俯视的"玩具感"，不能是仰视雕像）；
8. 细碎噪点纹理、过度渐变（卡通贴图色块要干净）。
