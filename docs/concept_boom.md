## 1. 一句话定位与设计支柱

**一句话**（沿用 design_boom §0）：竖屏单手、自动开火、割草式清关。玩家只做两件事——
**往哪走**（左手摇杆）和**什么时候放大招**（右下角）。瞄准、开火、换弹、拾取全自动。
打什么都"嘭"地爆开，60~90 秒一关。

四个设计支柱，是本文的最高裁判：任何机制若同时服务不到至少一条支柱，就不进 Must。

### 支柱 A — 单手零门槛，30 秒懂、全场不慌

- **定义**：操作负担趋近于零；玩家视线永远在"战场"而非"操作面板"。
- **机制来源**：竖屏俯视角固定相机（design_boom §1）；左手 DYNAMIC 摇杆 + 右手单大招键（§3.1）；
  瞄准/开火/换弹全自动（§3.2）；无第二摇杆；目标超屏边缘吸附箭头（§7.3）。
- **可检验锚点**：
  - **A1**：首次上手玩家（未看任何说明）从进入第一关到主动移动并击杀第一只敌人 **≤ 30 秒**。
  - **A2**：整局玩家**只用一只手**可完成（评审用单指/单键盘 WASD 方向测试均可通关前三关）。
  - **A3**：对局内没有任何需要"精确点按"的交互（按钮热区 ≥ 88px，§7.1）。

### 支柱 B — 打爆即爽：命中反馈 < 100ms，杀必开花

- **定义**：每一次有效输出都有即时、多感官、可累积的正反馈，构成"扫—停—扫"的呼吸节奏。
- **机制来源**：射击手感四件套——顿帧 / 噪声震屏 / 击退+挤压 / 命中粒子+飘字（§3.3）；
  击杀触发连击 Combo 与击杀播报（§7.2）；敌人被击先挤压再爆开（§2.3、§4.2）。
- **可检验锚点**：
  - **B1**：从子弹命中到玩家感知到反馈（顿帧/震屏/光效任一）**延迟 < 100ms**（评审以 60fps 录像数帧）。
  - **B2**：任意可打目标被打爆时，**≥ 3 种感官通道**同时反馈（视觉爆开 + 屏幕震 + 音效/击退）。
  - **B3**：三连击必触发一次视觉高潮事件（Combo 放大 / 击杀慢镜 / 白闪，任选其一，§7.2），保证"越打越爽"有台阶。

### 支柱 C — 压力可读，死因永远是自己走位失误

- **定义**：敌人软体无害、行为有前摇；玩家唯一会死的原因是"看到了但没躲开"，不是"看不见/看不懂"。
- **机制来源**：全敌人攻击前 0.4–0.8s 红色预警圈（§4.1）；敌人软体材质 + 随机偏转显得笨拙（§4.2/§4.3）；
  群体分离不叠成一坨，视觉信息不堵塞（§4.3）；倒下 3s 原地半血复活、无失败惩罚（§2.3）。
- **可检验锚点**：
  - **C1**：垂直切片内**每一种**敌人攻击都有 ≥ 0.4s 可识别预警（代码断言 + 视觉抽查）。
  - **C2**：评审试玩同一波次 3 次，在"预警出现后刻意走位躲开"情况下，被命中次数 **≤ 1 次/波**。
  - **C3**：玩家死亡回放中，致死攻击前 **≥ 0.4s 内屏幕上存在该敌人的预警视觉**（不允许"看不见就死"）。

### 支柱 D — 60~90 秒的碎片爽局，输了不亏、赢了想再来

- **定义**：单局短、节奏波浪式（紧—松—紧—松）、无体力和负反馈惩罚，天然适配碎片时间。
- **机制来源**：单关 60–90s、超 2 分钟切波次动画（§5.2）；三星评价弹性目标（§2.2/§5.3）；
  无体力/无门票/无强制广告（§2.3）；数值溢出保证 DPS 领先敌人成长（§2.3）；大厅永久升级兜底（§6.3）。
- **可检验锚点**：
  - **D1**：垂直切片单关时长中位数 **60–90s**（评审实测 3 局计时）。
  - **D2**：连续三关内至少出现一次"松"的爽关节奏（敌人血量×0.5 或数量×2 的波次，§5.2）。
  - **D3**：模拟"放弃重开"流程：玩家倒下复活后**波次进度零丢失**，且无任何货币/进度惩罚（代码断言）。

> **四条支柱内部有主次**：B 是生死线（对应 design_boom §9 的 M1 铁律"打第一只怪就爽"），
> A/C 是 B 的前提（不慌才有空看爆炸、可读才敢靠近），D 是留存包装。若资源冲突，优先保 B，其次 A/C，最后 D。

## 2. MDA 完整链

> 评审核心：不空谈"我们要做解压游戏"，而是逐条给出 **机制(M) → 动态(D) → 美感(A)** 的因果链。

### 2.1 总链图

```
[M] 无换弹，改过热 3s→1s（design_boom §3.2）
        ↓ 迫使玩家周期性停火
[D] 火力自然形成"扫—停—扫"，停火间隙用于走位/看战场
        ↓ 玩家体会
[A] 呼吸感节奏：不是在"肝输出"，而是在"跳舞"

[M] 命中四件套：顿帧≤80ms / 震屏分级 / 击退+挤压 / 粒子+飘字（§3.3）
        ↓ 每次命中都有跨感官确认
[D] 击杀串触发 Combo 音阶上行 + 播报（§7.2），连杀越多舞台越大
        ↓ 玩家体会
[A] 爽感的"爬楼梯"：从"打中"到"连杀表演"

[M] 加权最近自动瞄准 + 全自动开火（§3.2）
        ↓ 省掉操作带宽
[D] 玩家唯一决策是"走位与时机（大招）"，操作盈余全部投给观察
        ↓ 玩家体会
[A] 掌控感："是我的走位让这一波爆得漂亮"

[M] 软体敌人 + 全敌人带≥0.4s 前摇预警圈（§4.1/§4.2）
        ↓ 伤害全部可预期
[D] 玩家主动贴近→预判躲开→反打，形成"逗弄-闪避-收割"循环
        ↓ 玩家体会
[A] 压迫感被读解为"游刃有余"，敌人越近越不慌（压力可读）

[M] 无失败惩罚：倒下 3s 半血复活、进度保留（§2.3）
        ↓ 失败成本≈0
[D] 玩家敢于冒进尝试骚操作、敢于顶着波次边缘收割
        ↓ 玩家体会
[A] "随便玩"的松弛——没有"被惩罚"只有"打不过"，卸载焦虑

[M] 单关 60–90s + 波浪式难度 + 三星弹性目标（§5.2/§2.2）
        ↓ 目标短、反馈快、节奏有高低
[D] 一局结束后立刻被"再来一关"或"三选一成长"拉住（§6.1）
        ↓ 玩家体会
[A] 碎片时间的心流小口，赢了有成长、输了不亏
```

### 2.2 一条完整对局的 MDA 走读（垂直切片视角）

1. 进第一关：HUD 显示 波次1/3、分段血条、金币（§7.1）——**[A] 一眼读懂的安全感**。
2. 摇杆前推，DYNAMIC 摇杆在拇指落点出现（§3.1）——**[M→D] 移动零思考**，视角带着前瞻跟随（§3.4）。
3. 第一只果冻兵出现：绿果冻 sin 浮动 + 出生随机偏转，笨拙靠近（§4.2/§4.3）——**[A] "无害好笑"的第一印象**。
4. 自动锁定开火，子弹命中：击退 + 挤压 + 飘字 + 轻微震屏——**[B 支柱全开]**。击杀瞬间顿帧 + 果冻"爆"成碎片。
5. 第二波前摇：果冻兵胀大冒红光（§4.2 WINDUP）→ 玩家本能后退躲开冲撞 → 反打收割 → **玩家学会"看前摇=安全"**，此后所有敌人都复用同一阅读习惯（C 支柱闭环）。
6. 清空波次：出口开门 + 结算星级依次弹出、金币飞向计数（§7.2）→ 三选一升级（Should 层）→ 下一关。
7. 若中途倒下：3 秒读秒原地半血复活，屏幕泛红转暖（§7.2）——**[A] 被轻轻扶起而非判负**。

### 2.3 MDA 自检：最容易断的环节与对策

| 易断环节 | 断的表现 | 对策（已在设计内） |
|---|---|---|
| M→D：有命中四件套但无节奏 | 玩家狂按导致麻木 | 过热机制强制"扫—停—扫"（§3.2） |
| D→A：连杀无累积 | 爽感一条直线 | Combo 音阶上行 + 播报分级（§7.2） |
| M→D：预警有了但敌人贴脸才预警 | 躲不开 | 预警距离 = 冲撞射程 + 走位余量（§4.2 LUNGE_RANGE + 余量），评审按 C2 实测 |
| D→A：复活无成本反而无紧张 | 莽夫玩法无反馈 | 复活掉金币、三星零受伤评价失效（§2.2/§5.3），代价软但可见 |

## 3. 范围分层（Must / Should / Could）

> **垂直切片（P1 验证目标）= 全部 Must + 已标 [切片内] 的 Should**，实现上对齐 design_boom §9 的
> M0（骨架）→ M1（射击爽感生死线）→ M2（3 关循环）。每项给"验收断言"，可进 `tools/play_test.gd` 或评审人工核验。

### 3.1 敌人（design_boom §4.2 敌人表 → 三层）

| 层 | 敌人 | 行为（验收断言） | 出现 |
|---|---|---|---|
| **Must** | **果冻兵** | 追尾→前摇胀大红光 0.45s→冲撞；受击挤压/击退/爆碎（断言：预警可读、死亡必爆） | 1 关起 |
| **Must** | **水枪兵** | 保持 6–8m 停—射—走，弹速慢可躲（断言：子弹飞行 ≥ 0.5s 可视窗口） | 第 2 关引入 |
| Should | 炸弹兵 / 分裂兵 | AOE 自爆可坑同伴 / 死亡分裂 2 小只 | 第 3 关(爽关)/后续 |
| Could | 纸箱兵 / 磁铁兵 / 精英冰箱怪 / 大 BOSS | 绕后 / 拉扯 / 多阶段 / 场地机关 | 章节内容 |

> 设计意图：**果冻兵教"走位"，水枪兵教"距离与掩体"**——两者覆盖了割草类最核心的两种躲避直觉，
> 故为 Must。切片内第 3 关用"数量翻倍 + 血量减半"的爽关格式（§5.2）补足情绪高潮，不依赖新敌人。

### 3.2 武器（design_boom §6.1 → 三层）

| 层 | 武器 | 手感（验收断言） |
|---|---|---|
| **Must** | **泡泡枪** | 初始武器：高射速低伤、过热"扫—停—扫"（断言：0.22s 射速、连续 3s 过热 1s） |
| **Must** | **大招（全屏震荡/清屏技）** | 右下单键 + CD 圆环（§3.1）；命中全屏敌人重击退 + 强震屏 + 顿帧（断言：按钮 ≥88px、CD 可读） |

| Could | 链电 / 飞盘 / 黑洞枪 | 跳弹 / 穿透回旋 / 吸怪聚爆（最解压，放长线） |

## 4. 视觉锚点（文字精述，与 art_bible/contract 同源）

> 高饱和暖色气质总纲：**主角=暖橙，能量=亮青，危险=正红，奖励=金币金，敌群=高饱和冷色**。
> 同一饱和度亮度的"高饱和低对比"，让全屏信息一眼分层：暖橙永远属于"我"，青永远属于"我的火力"。

- **锚点 1 — 主角（泡泡队长）**：圆润胶囊形泡泡人，通体暖橙，戴一副亮青大护目镜，
  头顶一根小呆毛球；走路带轻微弹跳，被击短暂白闪；是屏上唯一的大块暖橙，玩家永远认得"这是我自己"。
- **锚点 2 — 果冻兵（敌群代表）**：半透明绿色果冻块，内可见小气泡，受击先压扁变形再"噗"地爆成一摊彩色碎片；
  全体敌人共用"圆、软、弹"的体态语言，即使红色炸弹兵也只是"红气球"，让人想戳而不是想逃。
- **锚点 3 — 战场**：暖米黄地面 + 暖橙/亮青拼色的几何格线；四周由高饱和暖色墙面包围（游乐园/嘉年华气质），
  天光柔和无硬阴影；视线范围内永远是"明亮的暖色游乐场"，没有黑黢黢的角落。
- **锚点 4 — 反馈层（爆开瞬间）**：击杀瞬间暖橙白闪光（透明度 ≤0.15、≤50ms，§3.3 防晕铁律）+
  青色冲击环扩散 + 高饱和彩色碎片四溅 + 金币金色飘字；危险预警则是地面上清晰的红色圆环 Decal——红只在"要躲"时出现。
- **锚点 5 — UI**：大圆角高饱和按钮（主按钮暖橙、信息按钮亮青），分段块血条（每格 1 血，受击格碎裂），

## 5. 数值手感结论（保留，自 design_boom，供垂直切片直接采用）

下列结论经评审**原样保留**，实现以 design_boom 对应章节为唯一基线，本概念不重定义数值：

- **手感四件套与参数**：顿帧击杀瞬间 `time_scale=0.05`、60–80ms 缓回；震屏按威力分级（击杀 0.04 / 爆炸 0.12 / BOSS 破防 0.25m）；击退 0.3–1.2m + squash&stretch 0.12s `EASE_OUT_BACK`（§3.3）。
- **防晕三铁律**：单次震动硬上限 + 连杀单次震动衰减 40%；顿帧 ≤80ms 且 0.5s 内至多一次；白闪透明度 ≤0.15 且 ≤50ms（§3.3）。垂直切片期即全量生效。
- **自动瞄准规则**：加权最近（距离 1.0 + 角度 0.6 + 威胁冲锋 ×1.5）；±8° 吸附；锁定 0.15s 防抖；过热 3s→1s（§3.2）。
- **移动手感**：加速 0.12s / 减速 0.10s、转向 slerp；相机死区 ±1.5m + 前瞻 2m；Physics Interpolation 常开（§3.4）。
- **敌人通用数值**：前摇 0.4–0.8s 红色预警圈；群体分离 0.8m；出生随机偏转 ±45°（§4.1/§4.3）。
- **难度节奏**：波浪式 紧—松—紧—松；每 5 关爽关（血量 ×0.5 / 数量 ×2 / 掉落 ×2）；单关 60–90s、>2 分钟切波次动画（§5.2）。
- **经济与复活**：金币→大厅永久升级（攻击 +5% / 移速 +2% / 拾取范围 +10%）；倒下 3s 半血复活进度保留；无体力无门票（§2.3/§6.3）。

> 切片内直接引用 `design_boom` 已定数值即自洽；M1 占位实现中出现的同类常量（如玩家 5 血、过热节奏）
> 属于工程落地取值，与本节不冲突（见 §6 差异表）。
