# 《百怪夜巡》M8 属性、战斗数值与属性面板需求

> 版本：2026-09-08
>
> 本文是 Boom 当前属性与成长系统的统一需求文档，覆盖主角属性、暴击、生命、防御、闪避、
> 敌人生命与攻击、基础攻击力、经验曲线、升级交互和属性面板。本文与早期 M7 属性章节冲突时，
> 以本文为准。

## 1. 目标与范围

Boom 需要从当前的“5 点生命 + 伤害/移速简单成长”升级为适合《百怪夜巡》的传统肉鸽属性系统。
系统必须满足：

- 3–5 分钟无尽波次中，玩家每次升级都有清晰、立即可感知的收益；
- 适配泡泡枪和大剑，不把某一种武器的数值直接套到另一种武器；
- 暴击、爆伤、闪避等高收益属性采用固定数额获得，不使用模糊的等级概念；
- 敌人生命、敌人攻击和波次成长互相独立，方便调难度；
- 属性面板显示的数值必须来自实际战斗结算函数；
- 属性面板打开后可以安全暂停游戏，不丢失波次、技能冷却或 XP 状态。

## 2. 当前代码基线与问题

当前实现仍是旧 M7 版本：

| 系统 | 当前实现 | 问题 |
|---|---|---|
| 主角生命 | 泡泡枪 5， 大剑 7 | 数值过小，无法承载防御、减伤、闪避等属性 |
| 主角攻击 | 泡泡枪子弹 1，大剑斩击 3 | 没有统一的基础攻击力概念 |
| 主角属性 | HP、移速、伤害三类 stack | 不能表达暴击、防御、闪避等肉鸽属性 |
| 敌人生命 | W1 约 3，后续 4–8 | 与主角新生命/攻击体系不匹配 |
| 敌人攻击 | 接触固定扣 1 | 没有敌人基础攻击力和波次攻击成长 |
| 暴击 | 不存在 | 没有暴击率与暴击伤害结算 |
| 防御 | 不存在 | 没有伤害减免结算 |
| 闪避 | 不存在 | 没有免伤判定 |
| 经验 | 普通 +1，精英 +8；升级需求 5、9、13…… | 精英经验偏高，升级选择 UI 缺失 |
| 升级 | `pending_upgrades` + toast | 玩家没有正常选择属性的界面 |
| 血条 | 按 HP 数量创建分段块 | 改成 50/70 HP 后会溢出，必须换连续血条 |

## 3. 属性总表

### 3.1 普通升级或固定效果可以获得的属性

| 属性 | 类型 | 是否进入普通等级升级池 | 说明 |
|---|---|---:|---|
| 伤害 | 固定增幅 | 是 | 增加最终攻击力 |
| 攻击速度 | 固定增幅 | 是 | 缩短普攻间隔；大剑对应挥斩周期 |
| 暴击率 | 固定数额 | 是 | 每次获得固定 `+3 个百分点` |
| 暴击伤害 | 固定数额 | 是 | 基础 150%，每次获得固定 `+15 个百分点` |
| 技能急速 | 固定增幅 | 是 | 缩短技能冷却 |
| 移动速度 | 固定增幅 | 是 | 增强走位能力 |
| 闪避率 | 固定数额 | 稀有选项 | 每次获得固定 `+3 个百分点`，设上限 |
| 回满生命 | 一次性效果 | 是 | 不增加最大生命，只将当前 HP 回满 |

### 3.2 不作为普通等级成长的属性

| 属性 | 规则 |
|---|---|
| 最大生命 | 不随等级增加；由主角/武器基础值决定 |
| 防御力 | 不随等级自动增加；只来自特定法器、技能、稀有事件或明确的特殊效果 |
| 攻击范围 | 不做通用属性；由武器和技能固定决定 |
| 穿透、投射物数量、拾取范围 | 暂不做通用属性，作为武器或技能专属效果 |

“不随等级增加”不等于数值永远不能变化：最大生命和防御力可以由明确的武器、法器或特殊效果改变，
但不能因为玩家等级提高就自动获得。

## 4. 主角生命系统

### 4.1 最大生命

目标生命制改为正常数值制：

```text
泡泡枪：50 HP
大剑：70 HP
```

大剑保留近战武器的生存补偿，但升级不再增加最大生命。

### 4.2 生命升级

生命类升级统一为：

```text
回满当前生命
```

规则：

- 不增加最大生命；
- 不产生 `hp_stacks`；
- 当前满血时不生成该选项；
- 选择后立即恢复，不占用后续持续属性槽位；
- `REPAIR` 技能是独立的固定回复效果，建议回复 15 HP。

### 4.3 血条

旧的“一个 HP 一个方块”必须移除，改为：

- 连续血条；
- 显示 `当前 HP / 最大 HP`；
- 颜色从米纸白逐渐转为朱砂红；
- 受伤时保留短暂红色反馈；
- 属性面板也显示同一数值。

## 5. 主角基础攻击力

### 5.1 基础攻击力定义

基础攻击力是由武器决定的初始攻击参数，不是主角等级，也不是当前伤害加成。

初始标定值：

| 武器 | 基础攻击力 | 作用 |
|---|---:|---|
| 泡泡枪 | 10 | 每发普通子弹造成 10 点基础伤害 |
| 大剑 | 30 | 每个弧斩命中目标造成 30 点基础伤害 |

敌人 W1 基础生命同步放大到 30，因此保留当前手感：

- 泡泡枪约 3 发击杀 W1 普通敌人；
- 大剑一刀击杀 W1 普通敌人。

### 5.2 最终攻击力

统一公式：

```text
最终攻击力 = floor(武器基础攻击力 × (1 + 伤害加成倍率))
```

建议普通伤害升级：

```text
每次获得：伤害 +10%
```

示例：

```text
泡泡枪基础攻击力 10，获得两次伤害加成：
最终攻击力 = floor(10 × 1.20) = 12
```

所有输出必须调用同一个结算入口：

- 普通子弹；
- fan 扇形弹；
- chain 闪电链；
- nuke 核爆；
- ring 环形弹；
- twin 双管弹；
- 大剑弧斩；
- whirl 旋风斩。

## 6. 暴击系统

### 6.1 暴击率

暴击率不采用“暴击等级”，而是每次获得固定数额：

```text
初始暴击率：0%
每次获得暴击率：+3 个百分点
```

示例：

```text
0% → 3% → 6% → 9% → 12%
```

### 6.2 暴击伤害

暴击伤害基础倍率固定为 150%，不分等级：

```text
基础暴击伤害：150%
每次获得暴击伤害：+15 个百分点
```

示例：

```text
150% → 165% → 180% → 195%
```

最终暴击伤害：

```text
暴击伤害 = 最终攻击力 × 暴击倍率
```

### 6.3 暴击判定

```text
if random() < crit_rate:
    damage = floor(base_damage × crit_multiplier)
else:
    damage = base_damage
```

规则：

- 普攻、技能、大剑都可暴击；
- 多目标技能按目标独立判定；
- chain 每一跳独立判定；
- nuke 每个受击目标独立判定；
- 暴击数字放大并使用朱砂红/灯火琥珀高亮；
- 暴击不能造成额外屏幕闪白，只增加轻微打击反馈。

## 7. 防御与伤害减免

### 7.1 防御来源

防御力：

- 不随等级自动增加；
- 不进入普通等级升级池；
- 只由法器、技能、稀有事件或特殊效果提供；
- 作为整数评级显示。

### 7.2 减伤公式

```text
伤害减免 = min(40%, 防御力 / (防御力 + 100))
```

示例：

| 防御力 | 伤害减免 |
|---:|---:|
| 0 | 0% |
| 10 | 9.1% |
| 20 | 16.7% |
| 30 | 23.1% |
| 50 | 33.3% |
| 70+ | 40%封顶 |

## 8. 闪避系统

闪避率作为正式生存属性保留，但收益必须受控：

```text
初始闪避率：0%
每次获得闪避率：+3 个百分点
闪避上限：20%
```

受伤结算顺序：

```text
1. 进行闪避判定
2. 闪避成功：受到 0 点伤害
3. 闪避失败：计算波次原始伤害
4. 应用防御力伤害减免
5. 扣除最终伤害
```

闪避成功：

- 不扣血；
- 不触发受击动画和受击无敌帧；
- 敌人的攻击冷却仍然消耗；
- 显示短暂的 `DODGE` / “避开”反馈；
- 不触发受击红屏和受击音效。

## 9. 敌人生命系统

### 9.1 基础生命

敌人生命从旧的 3 点制统一放大为 30 点制：

```text
BoomJelly.MAX_HP = 30
```

波次生命倍率继续沿用 M4 的独立曲线：

| 波段 | 普通敌人 HP |
|---|---:|
| W1–4 | 30 |
| W5–9 | 40 |
| W10–14 | 50 |
| W15–19 | 60 |
| W20–24 | 70 |
| W25+ | 80 |

公式：

```text
敌人 HP = round(30 × WAVE_HP_MULTS[波次档位])
```

### 9.2 精英生命

精英继续使用普通敌人生命乘区分：

```text
精英 HP = 当波普通敌人 HP × 3
```

因此 W5 精英为 120 HP，W10 精英为 150 HP。

敌人生命成长与敌人攻击成长必须是两套独立参数，不能因为敌人变肉就自动变得更痛。

## 10. 敌人攻击系统

### 10.1 原始攻击力

普通敌人接触攻击初始值建议为：

```text
敌人基础攻击力：8
```

未来敌人类型可以拥有不同基础攻击力，但都必须经过统一受伤结算入口。

### 10.2 波次攻击加成

```text
波次攻击加成 = min(floor((wave - 1) / 5), 4)
```

当前默认攻击值：

| 波次 | 原始接触伤害 |
|---|---:|
| W1–4 | 8 |
| W5–9 | 9 |
| W10–14 | 10 |
| W15–19 | 11 |
| W20+ | 12 |

### 10.3 统一受伤公式

```text
原始伤害 = 敌人基础攻击力 + 波次攻击加成

if random() < 闪避率:
    最终伤害 = 0
else:
    减伤 = min(40%, 防御力 / (防御力 + 100))
    最终伤害 = max(1, floor(原始伤害 × (1 - 减伤)))
```

主角当前的 `INVULN_TIME = 0.9s` 和敌人接触攻击冷却继续保留，作为连续接触伤害的节奏保护，
但不能替代闪避和防御属性。

## 11. 经验系统 review 与目标规则

### 11.1 当前曲线判断

当前经验曲线：

```text
普通击杀：+1 XP
精英击杀：+8 XP
升级需求：5、9、13、17、21……
```

按当前波次配额估算，W5 后约 4 级、W9 后约 7 级、W15 后约 11 级。
线性升级需求基本合理，适合 3–5 分钟单局；问题主要在精英经验过高和缺少升级选择 UI。

### 11.2 目标经验规则

保留：

```text
普通敌人：+1 XP
升级需求：xp_to_next(level) = 5 + (level - 1) × 4
等级上限：20
```

调整：

```text
精英敌人：+6 XP
```

经验继续在击杀完成时直接获得，不额外增加：

- 波次 XP；
- 木箱 XP；
- 清波 XP；
- 后期波次 XP 倍率。

### 11.3 升级流程

```text
获得升级
→ 暂停战斗
→ 弹出 3 张随机升级卡
→ 玩家选择一张
→ 立即应用固定效果
→ 恢复战斗
```

暴击和爆伤卡不显示“等级 1/2/3”，而显示固定获得量：

```text
暴击率 +3%
暴击伤害 +15%
```

重复获得时直接相加。

建议升级卡文案：

| 卡片 | 效果 |
|---|---|
| 破印 | 伤害 +10% |
| 追灯 | 攻击速度 +10% |
| 朱砂一闪 | 暴击率 +3% |
| 破煞 | 暴击伤害 +15% |
| 灵息回转 | 技能急速 +8% |
| 轻身 | 移动速度 +8% |
| 回灯 | 当前生命回满 |

防御力不进入普通升级卡池；闪避率建议作为稀有卡或特殊效果出现。

## 12. 主角属性面板

### 12.1 定位

属性面板是“查看面板”，不承担：

- 当前构筑展示；
- 武器装备管理；
- 技能树管理；
- 升级选择。

### 12.2 入口与暂停

HUD 增加灯匣/属性按钮。点击后：

```text
打开属性面板
→ SceneTree.paused = true
→ 属性面板使用 PROCESS_MODE_ALWAYS
```

暂停期间：

- 敌人停止移动和攻击；
- 子弹停止飞行；
- 波次倒计时停止；
- 技能冷却停止；
- XP 和 combo 停止变化；
- 面板按钮、关闭按钮和返回键仍可操作。

关闭方式：右上角关闭、底部“返回战斗”、Escape 或移动端系统返回键。

## 14. 验收标准

### 数值

- 泡泡枪初始最大生命为 50；
- 大剑初始最大生命为 70；
- 生命升级不改变最大生命，只回满当前生命；
- 泡泡枪基础攻击力为 10；
- 大剑基础攻击力为 30；
- W1 普通敌人 HP 为 30，W5 为 40，W10 为 50；
- 普通敌人接触伤害 W1/W5/W10 为 8/9/10；
- 暴击伤害初始为 150%；
- 每次暴击率获得固定 +3%；
- 每次暴击伤害获得固定 +15%；
- 防御力不会随等级自动增加；
- 闪避率能独立触发完整免伤，且不超过上限；
- 所有攻击和受伤来源都走统一公式。

### 经验

- 普通击杀 +1 XP；
- 精英击杀 +6 XP；
- XP 曲线 5/9/13/17……保持；
- 满血时不出现回满生命卡；
- 升级时战斗暂停，选择完成后恢复；
- 不再依赖玩家看不见的 `pending_upgrades` 消费流程。

### 属性面板

- 面板打开时 `get_tree().paused == true`；
- 面板打开期间 wave、XP、技能 CD、敌人位置均不变化；
- 面板关闭后战斗继续；
- 面板显示基础攻击力与最终攻击力；
- 面板显示暴击率、暴击伤害、防御、减伤和闪避率；
- 面板不显示当前构筑、武器、技能树或技能槽；
- 面板所有数值与实际战斗快照一致。

## 15. 明确不做

- 不做通用攻击范围属性；
- 不做闪避和防御的无限堆叠；
- 不做最大生命随等级增长；
- 不做暴击等级或爆伤等级；
- 不做波次额外 XP 和后期 XP 倍率；
- 不做属性面板内的技能装备操作；
- 不把旧 M5 的 5 HP、7 HP、1 伤害和 3 HP 敌人基线继续当作新系统目标。
