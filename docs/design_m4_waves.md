# 《砰砰小队》M4 设计增量：波次系统（design_m4_waves.md）

> 归属：`docs/design_boom.md` §9 里程碑 M4 · 前置：M2 弹幕技能（`design_m2_danmaku.md`）、
> M3 反馈层已上线 · 本文只做设计，不改代码。

---

## §1 概述与目标

**一句话**：把无尽模式"数量温和递增"的持续刷新，升级为**有节奏的波次攻防**——
波内有配额、波间有喘息、每 10 波一个可感知的台阶、每 5 波一个精英爽点。

设计锚点（继承自 `design_boom.md` 旧版 §5.2 "紧—松—紧—松"波浪曲线，P1 概念版）：

- **解压向**：难度感来自数量与视觉压迫，不来自"打不动"（玩家 DPS 恒定，敌人血量
  增速永远贴着玩家击杀节奏走，不会出现打不死）。
- **碎片时长**：单局 3~5 分钟；30 秒内必有一次爽点（前 3 波 20 秒内清完 + 首个精英波）。
- **前松后紧、10 波一个台阶**：台阶 = 配额跳升 + 速度系数上探 + 强制精英波，三件事
  同帧发生，让"撑过 10 波"成为玩家能说出口的成就。

## §2 现状与差距

### 2.1 现状核实（基于 `games/boom/scripts/core/boom_game.gd` @ c785352）

当前已有一套**很薄的波次骨架**，而非纯持续刷新：

- **波的定义**：`wave` 从 1 起；每波配额 `_wave_quota(n) = clamp(3 + (n-1), 3, 24)`，
  即每波 +1 只、封顶 24；同屏上限 `_max_alive() = clamp(2 + wave, 2, 9)`；
  刷怪间隔 `_spawn_interval() = clamp(1.7 - wave * 0.15, 0.7, 1.7)` 秒。
- **刷新位置**：四边随机刷怪（`_spawn_edge_enemy`），与玩家距离 ≥ 4.0 兜底。
- **波次推进**：配额刷满 **且** 场上清空 → 发 `wave_cleared(wave, bonus)`（奖励
  `20 + wave*10` 分）→ 固定间歇 **1.8s** → `wave+1`、发 `wave_started`。
- **难度递增**：仅体现在"数量 +1/波、间隔 -0.15s/波"两条线性上。
  敌人本体属性（`BoomJelly.MAX_HP=3`、`WALK_SPEED=1.7` 等）全部为常量，**无任何
  波次缩放**。

### 2.2 差距对照

| 维度 | 现状 | M4 目标 |
|---|---|---|
| 数量曲线 | 线性 +1，W22 触顶 24 后走平 | 台阶式，W10 跳升，封顶 30 |
| 血量/速度 | 恒定，永不变化 | 阶梯系数，每 5 波一档 |
| 曲线手感 | W7 后（间隔触底 0.7s）彻底走平，5 分钟局后半段无新鲜感 | 前 10 波紧—松交替，10 波一台阶 |
| 波间歇 | 固定 1.8s，无任何表现 | 阶梯递减 2.5→1.0s，带倒计时 UI |
| 波次感知 | 仅结算面板星级暗示（2/4/6 波） | 开场横幅 + 间歇倒计时 + 台阶/精英提示 |
| 精英 | 无 | 每 5 波一只，参数放大不加行为 |

## §3 波次机制

### 3.1 波的定义（沿用现骨架，不推翻）

- 一波 = 一个配额（quota）+ 一个出生池；配额刷满且场清 → 波结算（奖励分）→
  间歇倒计时 → 下一波。
- 信号复用既有 `wave_started` / `wave_cleared`，新增携带信息不改签名语义
  （bonus 数值改为查表）。

### 3.2 波内配额曲线（数量）

公式（默认值）：

```
quota(n) =
  n<=4  : 2 + n                    # W1..W4 = 3/4/5/6，教学段
  n<10  : 9 + 2*(n-5)              # W5..W9 = 9/11/13/15/17，稳步加压
  n>=10 : 18 + 2*(n-10), 上限 30   # W10=18 起台阶，W16 触顶 30
```

要点：W10 从 17 跳到 18 看似温和，但叠加"血量上一档 + 精英波"三者同帧，玩家
体感是明显跃升；纯数字跳变（如 17→24）在自动瞄准下只表现为清场变慢，不如三因素
叠加可感知。

### 3.3 敌人属性阶梯（血量 / 速度系数）

对 `BoomJelly` 的 `MAX_HP` / `WALK_SPEED` / `LUNGE_SPEED` 按当波系数缩放
（`hp = round(3 * hp_mult)`，速度乘系数），不改 FSM：

| 波段 | 有效 HP | 速度系数 | 体感 |
|---|---|---|---|
| W1–4 | 3 | 1.00 | 两发内死，纯爽 |
| W5–9 | 4 | 1.00 | 多打一发，节奏不变 |
| W10–14 | 5 | 1.10 | 台阶①：明显变肉 |
| W15–19 | 6 | 1.20 | 需要用技能清场 |
| W20–24 | 7 | 1.30 | 台阶②：贴脸冲撞必须躲 |
| W25+ | 8（封顶） | 1.30（封顶） | 数值墙封顶，靠数量压迫 |

**速度封顶 1.30 是硬红线**：前摇 0.45s + 冲撞 11.0 的机制下，再快就不可躲，
违背"没有失败惩罚"的解压原则。

### 3.4 波间间歇与倒计时

| 波段 | 间歇（默认） | 调整空间 |
|---|---|---|
| W1 前（开局准备） | 2.0s | 1.5–3.0 |
| W1–4 | 2.5s | 2.0–3.0 |
| W5–9 | 2.0s | 1.5–2.5 |
| W10–14 | 1.5s | 1.0–2.0 |
| W15+ | 1.0s（下限） | 0.8–1.5 |

- 间歇期是"松"半拍：玩家捡金币、看飘字、等倒计时——**喘息是为了下一波更爽**。
- 倒计时 UI 见 §5；逻辑上就是现有 `_next_wave_cd` 换成查表值。

### 3.5 波结算奖励

`bonus = 20 + wave * 10`（沿用现值不变，只是改为常量查表），W10/20 台阶波额外
×2（台阶仪式感的一部分，落金币不落分数也可，实现取分数方案，成本最低）。

### 3.6 节奏验收粗算（玩家 DPS ≈ 4.5 发/s · 敌 3hp→0.67s/杀）

| 时间点 | 预期进度 |
|---|---|
| 0:30 | 已过 W3–W4（首个爽点达成） |
| 1:00 | W5 精英波（第二个爽点） |
| 1:30–2:00 | W7–W8，⭐⭐（4 波线）早达成 |
| 3:00 | W10–W11 台阶 |
| 5:00 | W13–W15，普通玩家光荣阵亡 |

⭐⭐⭐（6 波）从"新手可达"下修为"熟练可达"——现曲线下 6 波太容易，星级含金量
被动提升，无需改 `result_stars` 阈值（见 §8）。

## §4 精英敌人（可选增强，控制实现成本）

**原则：不加新 AI 行为。** 精英 = 普通果冻兵 + 参数放大 + 死亡掉落，复用
`BoomJelly` 全部 FSM（前摇→冲撞→冷却）。

- **周期**：每 5 波一只（W5、W10、W15…），即该波**最后一个**刷出的敌人。
- **参数放大**：血量 = 当波有效 HP × **3**；体型 scale × **1.4**；速度 × **0.85**
  （更大更肉但更慢——好认、好打、有"死得其所"的仪式感）。
- **死亡掉落：金币雨**：死亡点爆开 **8 枚金币**（每枚 5 金币值，合计 40），沿用
  `prop_broken` 的金币结算与飘字管线（金币雨为表现层粒子 + 逐枚入账，走既有
  `coins` 字段，不新增经济系统）。
- **识别**：体型差 + 出生瞬间 telegraph 圈放大一档（复用现有 `_telegraph` 网格），
  不做专属贴图/音效（美术留 M5）。
- **血条**：不做。精英血量 ≤ 9×3=27，两轮扫射的事，飘字已足够反馈。

## §5 UI / 反馈需求

| 反馈点 | 内容 | 复用 / 新增 |
|---|---|---|
| 波次开场横幅 | 中央大字 "WAVE N"（台阶波 "WAVE 10 — STAGE UP!"） | **复用 M3 击杀播报的中央大字管线**，挂 `wave_started` 信号 |
| 波间歇倒计时 | 间歇期屏幕上沿小字 "下一波 3·2·1" | **复用 M3 飘字管线**（每秒一跳，最后 1s 变色放大） |
| 精英波提示 | W5 横幅变体 "WAVE 5 · ELITE!"（红字） | 复用播报管线，仅换文案与颜色 |
| 精英死亡金币雨 | 8 枚金币散射 + 逐枚 "+5" 飘字 | **复用 `prop_broken` 金币结算 + 飘字**，新增散射粒子（fx 层小活） |
| 波结算 | 清场瞬间 "+130" 奖励飘字（波中心） | 复用 `wave_cleared(bonus)` + 飘字管线（现 bonus 已发但无表现，M4 补上） |

逻辑层零新增 UI 依赖：`boom_game.gd` 只发信号（现有 `wave_started`/`wave_cleared`
已够用），全部表现挂 `main.gd` 订阅端。

全部数值收敛为常量，调参不改逻辑。**默认值** / **调整空间** 两列：

| 常量（建议名） | 默认值 | 调整空间 | 说明 |
|---|---|---|---|

| `WAVE_QUOTA_MID_BASE` | 9 | 8–10 | W5–9：quota = 9+2*(n-5) |

| `WAVE_REST_EARLY` | 2.5s | 2.0–3.0 | W1–4 间歇 |
| `WAVE_REST_MID` | 2.0s | 1.5–2.5 | W5–9 间歇 |
| `WAVE_REST_LATE` | 1.5s | 1.0–2.0 | W10–14 间歇 |
| `WAVE_REST_MIN` | 1.0s | 0.8–1.5 | W15+ 间歇下限 |
| `WAVE_REST_READY` | 2.0s | 1.5–3.0 | 开局准备时长 |
| `WAVE_BONUS_BASE` | 20 | 15–30 | 波奖励基数 |
| `WAVE_BONUS_PER_WAVE` | 10 | 8–15 | 每波增量 |
| `WAVE_STAGE_BONUS_MULT` | 2.0 | 1.5–3.0 | W10/20 台阶奖励倍率 |
| `ELITE_EVERY_N` | 5 | 4–6 | 精英周期（波） |
| `ELITE_HP_MULT` | 3.0 | 2.5–4.0 | 精英血量倍率（叠当波系数） |

| `ELITE_SPEED_MULT` | 0.85 | 0.8–0.9 | 精英速度 |

## §7 测试要点（无头可断言，`play_test` 风格）

`boom_game.gd` 保持零 UI 依赖，以下全部可在无头环境 `step()` 驱动断言：

1. **波次推进条件**：`force_wave_spawned_done()` + 逐个击杀清场 → 断言
   `wave_cleared` 信号（wave、bonus 数值查表正确）→ step 超过间歇时长 →
   `wave == n+1` 且 `wave_started` 已发。
2. **配额公式边界**：`_wave_quota(1)==3`、`_wave_quota(4)==6`、`_wave_quota(5)==9`、
   `_wave_quota(10)==18`、`_wave_quota(15)==28`、`_wave_quota(16)==30`（首次触顶）、
   `_wave_quota(99)==30`（封顶）。
3. **间歇计时**：`_between_waves == true` 期间 `_next_wave_cd` 按 §3.4 查表值递减；
   W1–4 波间歇为 2.5s（step(2.4) 后未换波、step(2.6) 后已换波）。
4. **属性缩放**：W5 波 `spawn_enemy_at` 出的敌人 `hp == 4`；W10 波 `hp == 5`、
   移动速度 ≈ 1.7×1.1（容差 0.01）。
5. **精英波标记**：W5 配额最后一个刷出的敌人 `hp == round(4*3)==12`、
   `radius ≈ 0.6*1.4`；击杀后 `coins` 增量 == 40（金币雨逐枚入账断言总额即可）。
6. **星级兼容回归**：既有 `result_stars` 断言（2/4/6）不因本改动失败——阈值不动，
   只验曲线可达性（§3.6 粗算留档，真机另验）。
7. **auto_spawn=false 回归**：手动 `spawn_enemy_at` 路径不受配额逻辑影响。

## §8 验收标准与范围边界

### 验收标准

- [ ] 无头测试 §7 全绿（CI 通过）。
- [ ] 5 分钟标准局：30s 内过 W3、1min 遇首个精英、3min 触台阶①（真机目检）。
- [ ] W10 台阶波三要素（配额跳升+血量上一档+精英）同帧发生，横幅可见。
- [ ] 星级阈值 2/4/6 不改，⭐⭐ 在 2 分钟内仍可达成。

### 范围边界（M4 明确不做）

- ❌ **不加新敌人类型**（水枪兵/炸弹兵等留待后续，精英仅参数放大）。
- ❌ **不改技能系统**（M2 三技能数值、手势不动）。
- ❌ **不做关卡/退出机制**（无尽模式死亡即结算不变，不做"打到 W10 通关"）。
- ❌ **不做数据驱动 levels.gd Resource**（旧 §5.1 的关卡表方案不恢复，常量区查表够用）。
- ❌ **不改结算/星级阈值**（若实测 6 波过难，属 M4 上线后调参，不改结构）。
- ❌ **不做精英专属美术/音效**（留 M5 素材里程碑）。
