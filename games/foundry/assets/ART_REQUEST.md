# 素材需求书 · 背包工厂 Backpack Foundry

本文件是美术素材的唯一规格来源。生成脚本放在 `games/foundry/tools/gen_assets.py`，
产物直接写入下面的相对路径。所有 PNG 必须 **RGBA、透明背景**（背景图除外）。

## 统一风格（flat-cartoon，与 shared/assets/styles/flat-cartoon/contract.yaml 一致）

- 扁平矢量卡通风：粗黑色描边、高饱和纯色填充、简单几何形状
- **禁止**：渐变、阴影、噪点、写实材质、文字、发光
- 描边颜色 `#1A1A1A`，描边宽度 = 画布边长的 2%（512px 画布 → 10px；256px → 5px）
- 主体居中，占画布 72%–80%，四周留白均衡
- 每个图标只用 **1 个主色 + 1 个深色（同色系压暗 35%）+ 黑白**，不要第三种色相

### 3. 背景 `bg/bg_workshop.png` — 1280×720，不透明

工厂车间内景。**低对比、低饱和**，不能抢 UI 焦点：

- 底色 `#EDE8DC`
- 下半部地板 `#D8D0BE`，占画面底部 28%
- 墙面散布 3–4 组管道剪影（`#C9BFA8`），顶部一排齿轮剪影（同色）
- 整体做一层白色半透明压暗（alpha 60），保证前景 UI 可读
