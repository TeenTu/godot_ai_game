# 素材需求书 · 背包工厂（移动端·买量美术风）

本文件是美术素材的唯一规格来源。生成脚本 `tools/gen_assets.py`（可整体重写），
产物写入 `assets/icons/` `assets/ui/` `assets/bg/`。全部 PNG 必须 **RGBA**（背景图除外）。

## 统一风格（买量手游风，参考《向僵尸开炮》类）

- 高饱和暖色 + 粗黑描边 + 强白色高光 + 简单底部投影，造型大而圆、表情夸张
- 描边色 `#2B2B2B`，宽度 = 画布边长的 6%（512px → 30px；256px → 15px）
- **每个图标必须**：① 圆角方块背景色块（圆角 22%，用主色）② 主体几何（粗描边）
  ③ 左上白色高光弧/月牙 ④ 主体底部同色加深 40% 的小椭圆投影
- **禁止**：渐变（背景图除外）、写实材质、文字、噪点、细线细节（太细会被描边吞掉）
- 主体占画布 60%–70%，四周留白均衡（背景色块约占 85%）

暖色买量风场景，不能抢 UI：

- 垂直渐变：顶部 `#FFE0A3` → 中部 `#FF9A4D` → 底部 `#D94E1E`
- 底部 30% 是地面：`#B33A18`，画 3-4 栋卡通工厂剪影（`#C94B1F` 更深 15%）

## 验收标准

- 全部文件可被 Pillow 重新打开；图标四角 alpha = 0；背景不透明
- 打印 4×2 拼图预览 `icons/_preview.png`（1024×512 白底）供人工目检
- 每个图标都要有高光和投影（规则性写死，不要随机）
