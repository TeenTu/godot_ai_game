# Boom 画面优化验证记录

2026-09-09。本记录对应未发布的工作区改动，不代表线上已更新。

## 本批证据与改动

- 实际 OpenGL Compatibility 渲染确认：水平地面已恢复，原代码对默认 XZ PlaneMesh
  再转 -90 度会把它竖起。移除了地面上干扰角色轮廓的亮色大网格。
- 顶部卡片由橙/亮青改为深靛底、旧铜细边、米纸文字；技能环减薄，主技能色
  统一为灯火琥珀、灵雾青绿与朱砂红。底部手势说明提高对比度。
- 背景插画通过边缘遮罩限制覆盖范围，避免灯笼和屋檐浮在战斗中心。
- 行走转向保留帧号与帧内进度；对角线附近采用 18% 轴向滞回，避免方向贴图抖动。
- 武器层用 set_frame_and_progress 同步身体帧，避免分别赋值重置进度。
- 近战五帧改由战斗阶段驱动：两帧前摇、一帧命中窗、两帧收招；避免固定 16fps
  在约 0.31 秒提前播完，也使攻速加成后的前摇与出手画面保持对应。
- 武器层关闭独立播放时钟，通过身体换帧信号同步；共用身体中心并以精灵画布偏移定位，
  避免自动瞄准旋转挂点。背向使用较低绘制优先级，受击闪烁同步身体。
  本轮截图位于 build/visual-review-grip，正面头脸已不被灯头遮挡；精确逐帧握持仍需打磨。

## 可重复检查

从 Boom 项目根执行 Godot：

```text
--headless --script res://tools/visual_review.gd
--resolution 720x1280 --audio-driver Dummy --script res://tools/visual_review.gd -- --capture-dir=<绝对目录>
```

第一条检查转向、对角线输入和地面朝向。第二条必须使用实际渲染器，输出四向 PNG。
本次前后对照分别位于仓库 build/visual-review 与 build/visual-review-refined。
