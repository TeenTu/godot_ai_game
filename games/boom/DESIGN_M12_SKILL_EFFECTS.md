# 《百怪夜巡》M12：技能效果完成与触发链修复

> 状态：2026-09-10 已实现。本文覆盖 M10 双武器技能树的运行时效果、触发槽与表现契约。

## 1. 问题与目标

旧实现把 `equipped` 同时当作构筑槽和手势槽。默认构筑为
`[lamp_quick_wick（被动）, lamp_firefly_volley（主动）]`，因此 tap 总是命中不可施放的
被动，玩家只能猜测用左滑触发第一个主动技能。更多被动加入后，同样会吞掉左滑或右滑。

本里程碑要求：

- 12 个技能节点都必须产生真实战斗效果；
- 被动技能装备后立即常驻生效，但不能占用玩家的战斗触发位；
- 四个主动技能必须从触摸输入一路进入冷却、战斗判定、动画、音效与独立视觉表现；
- 普通与进化参数只维护一份，判定和表现读取同一数据源。

## 2. 构筑槽与主动触发槽

- `equipped`：最多 3 个节点，允许主动与被动混排，决定本局构筑容量。
- `passive_equipped()`：当前构筑中的被动节点，装备后由 `_refresh_passives()` 落地。
- `active_equipped()`：保持装备顺序，只投影主动节点。
- tap / 左滑 / 右滑分别触发 `active_equipped()[0/1/2]`。
- 战斗 HUD 与 `sk_slots` 只展示主动投影；`sk_passives` 单独暴露被动列表。
- `cast_skill()` 只允许施放当前已装备的主动技能；被动、未装备技能、冷却中技能均拒绝。
- 移动端 tap 容错为 0.35 秒、24px；按钮圆形命中区另保留 12px 拇指容错。

## 4. 四种独立主动表现

| 主动技能 | 表现语言 |
|---|---|
| 流萤散射 | 独立施法身体动作、琥珀枪口闪光、与实际扇角一致的定向灯火扇面、可见灵印弹道 |
| 魂灯结界 | 独立施法身体动作、青绿 8m 全向扩散灯阵、琥珀灵火爆发、12/18 枚可见环射弹道 |
| 泼墨锋 | 独立施法身体动作、与真实 100°/5m 或 130°/6m 判定一致的青墨扇面、命中震屏与飘字 |
| 朱砂封域 | 独立施法身体动作、与真实 4.5m 或 5.5m 判定一致的朱砂圆域、青绿灵火爆发与重反馈 |

扇面、圆域和粒子发射器全部预建并循环复用；施放时不创建新的特效节点。`BoomSkillEffects`
是四个主动技能普通/进化参数的唯一表，`BoomGameSkillCasts`、`BoomSkillSystem` 与
`BoomSkillPresenter` 共同读取它。

## 5. 验收标准

- 默认新档直接 tap 能触发流萤散射，左滑/右滑不会被被动节点占位。
- 装备第二个主动技能后，左滑稳定触发它；第三主动槽为空时右滑安全忽略。
- 八个被动分别有真实数值或形态断言，其中 FLOWING SCRIPT 必须覆盖连招全部三阶段。
- 四个主动分别有真实发射/伤害断言，并有互不混用的表现类型与精确范围/扇角断言。
- 普通与进化形态的发射数、范围、扇角、目标上限和伤害倍率都有确定性测试。
- Godot import、无头 play test、gdlint、gdformat、Web release 导出和实机截图均通过。
